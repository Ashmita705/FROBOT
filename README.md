# Frobot

![CI](https://github.com/ashmita705/frobot/actions/workflows/ci.yml/badge.svg)

Frobot is an AI-powered accessibility companion robot, built to help elderly people, visually impaired people and children with special needs.

This repo holds the AI modules that will come together in the robot. I'm building them one at a time.

## Modules
| Module | What it does | Status |
|---|---|---|
| [Object Detection](object-detection) | Describes surroundings out loud, with direction | Done |
